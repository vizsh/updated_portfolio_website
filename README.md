## 🌟 Key Highlights & Features

### 1. 🛋️ 3-Tier Seamless Camera Navigation
- **Room View (Panoramic Overview)**: Wide isometric view showcasing the full physical study, ergonomic swivel chair, lush potted Monstera house plant, papers, and ambient window lighting.
- **Desk View (Workstation)**: Front-facing sitting view right in front of the vintage banker's desk lamp, mechanical keyboard, ball mouse, and steaming coffee mug.
- **Screen View (Retro Operating System)**: Close-up immersion into the CRT monitor screen. TopHUD automatically vanishes, giving unobstructed focus to Windows 98.
- **Dynamic Zooming**: Smooth mouse wheel scrolling notches effortlessly between `Room ⇄ Desk ⇄ Screen`.

### 2. 💡 High-Contrast Atmospheric Day & Night Study Mode
- **☀️ Day Mode**: Crisp, bright natural daylight streaming through the study window with warm sunlight directionals and sky ambient fill.
- **💡 Night Mode**: Deep midnight study atmosphere. The emerald green banker's desk lamp shines an intense warm amber spotlight cone across the desk surface, while the CRT monitor casts a vivid electric cyan phosphor glow forward onto the keyboard and mouse.
- **Translucent Lamp Glow**: Translucent emerald shade with glowing incandescent filament bulb and metallic chain pull sound.

### 3. ⌨️ Interactive Physical Desk & Spatial Feedback
- **Mechanical Keyboard**: Click or type to trigger authentic clicky Cherry MX Blue mechanical switch audio.
- **Vintage Ball Mouse**: Click to trigger classic trackman click sound.
- **Drifting Coffee Cup Steam**: Real-time procedural GLSL steam wisps rising from the ceramic mug. Click to play ceramic clink.
- **PC Tower Power Button**: Tactile mechanical relay thud and floppy whirr that boots up the workstation and dollies directly into the CRT display.
- **Potted Monstera Plant**: Interactive rustle sound effect on click.

### 4. 🪟 Authentic Windows 98 Operating System
- **My Showcase Explorer**: Deep dive into Jeevesh's profile, Hackathon Champion accolades, 9.6 CGPA, and top verified repositories:
  - `Jarvis_Hedge_Fund` (72 commits, 532 passing tests, bilingual EN/HI, deterministic financial checks)
  - `Drishti_AI` (79 commits, modular 5-stage CV perception pipeline, 92% mAP50 benchmark, 1st Place Drishti AI Hackathon)
  - `DecentralisedIntelligence_NeuroScope3d` (42 commits, real MONAI 3D tumor segmentation, 17/17 judge tests)
  - `Pillai_Hotel360` (56 commits, 12 decision-science modules, CI badge)
  - `SIH_IBVAP` (35 commits, Ministry of Home Affairs / SSB PS)
- **Projects Explorer & Deep Dive**: Live links, source code, and verified metrics.
- **Terminal (MS-DOS Prompt)**: Interactive command-line with `help`, `repos`, `jarvis`, `drishti`, `skills`, `clear`, and `matrix`.
- **Snake.exe**: Authentic arcade snake game with score tracking, sound effects, and smooth retro controls.
- **Minesweeper**: Full Windows 98 implementation with smiley button and retro timer.
- **Display Properties**: Control Panel with customizable wallpapers (Windows 98 Teal, Midnight Navy, Cyber Matrix Green, 90s Sky, Vintage Slate) and CRT phosphor scanline intensity slider.
- **Taskbar & Start Menu**: Active window pills, start menu cascade, system tray with real-time clock, volume toggle, and a `"🛋️ Desk"` quick return button.
- **Global Escape Key (`Esc`)**: Instantly steps back from Screen ➔ Desk ➔ Room.

## 🛠️ Tech Stack & Architecture

- **Core**: React 19, TypeScript, Vite
- **3D Graphics**: Three.js, React Three Fiber (`@react-three/fiber`), Drei (`@react-three/drei`)
- **Audio Engine**: Web Audio API zero-latency procedural synthesizer + authentic mechanical audio clips
- **Deployment**: Vercel ready with zero configuration (`vercel.json`)

## 🚀 Getting Started

### Prerequisites
- Node.js 18+
- npm or yarn

### Installation
```bash
# Clone the repository
git clone https://github.com/vizsh/updated_portfolio_website.git

# Enter project directory
cd updated_portfolio_website

# Install dependencies
npm install

# Start development server
npm run dev
```

### Production Build
```bash
npm run build
npm run preview
```
